# Miko Margin Health for Odoo

Finds products priced below cost, stops orders that lose money at confirmation on
rules you set, and identifies pricelist rules that can never apply.

Published on the Odoo Apps Store by Tripster Developers.

| Branch | Odoo | Tests |
|---|---|---|
| `14.0` `15.0` `16.0` `17.0` `18.0` `19.0` | 14 to 19 | 30 passing each |

No external services. Runs on Odoo.sh and on premise.
