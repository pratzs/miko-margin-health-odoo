Odoo lets you sell below cost and says nothing at all.

Set a sales price under the cost price and Odoo saves it without a murmur. The quotation looks normal, the order confirms, the invoice posts. The loss only surfaces when somebody runs a margin report, if anybody ever does.

This is not hypothetical. The demo data that ships inside Odoo itself contains six products priced below their own cost, one of them at minus 308 percent. Install this on a fresh database with demo data and it finds every one.

Worst first, with the cash you lose per unit and the percentage.

Then it stops the next one happening

A report tells you about the loss next month. This refuses to let it through. Set the margin your business actually needs and Odoo enforces it at the one moment it can still be changed: when somebody confirms the order.

SettingWhat it does
Report onlyNever interrupts anyone. The audit still fills in.
WarnLets the order through and writes the figures to its log, so the decision is answerable for later.
BlockRefuses the confirmation. Only a user holding the margin override permission can push it through, and that override is logged too.

Measured per line, on the order total, or both. Every setting is per company, so a group with several trading entities runs different rules in each.

The leak it actually closes is the discount. A price can look perfectly healthy and the discount is what takes it under water. The check reads the line subtotal, so the discount is already inside the number.

Pricelist rules that can never apply

Nothing else on this store does this.

Odoo evaluates pricelist rules in a fixed order and returns the FIRST one that matches. A rule sitting behind another that already covers every case it would cover is dead: it is in the list, it looks active, it has a discount on it, and it has never once applied to anything. Odoo never tells you.

It reproduces Odoo's own ordering, then names the rule that wins instead.

Expired rules and rules that have not started yet are separated out, so a dead rule is never confused with one that is simply waiting.

It does not cry wolf

A control that fires on legitimate business gets worked around, and then it is worth nothing. These are never counted against anyone:

Deliberate loss leadersTick a product as sold below cost on purpose and it leaves the rules entirely.
Products with no costA missing cost is an unanswered question, not a perfect margin. Without this every uncosted product would block every order.
Free linesSamples, goodwill replacements and full discounts are deliberate.
Exempt categories, pricelists and customersClearance ranges, staff pricelists and intercompany accounts, set by you.
Sections, notes and down paymentsCarry no goods and no margin.

Thirty automated tests ship inside the module and are run against Odoo 14 through 19 before every release. Half of them exist purely to prove the module stays quiet when it should.
